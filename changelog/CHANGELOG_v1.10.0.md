# **[1.10.0] - 2026-10-26**

AI apps via MCP, faster startup, ratings, inline DRC reviews, daily fields, exports and deeper analytics.

### **AI Apps (MCP)**

![MCP](https://github.com/user-attachments/assets/7a2212af-64a3-464f-93a8-7b92524322de)
Connect Claude, ChatGPT/Codex, Hermes or Grok Bot to analyse trades, draft reviews and update your journal.
_Access via Settings → AI apps (MCP) · [Setup guide](https://journalit.co/docs/ai-apps)_

### **Performance Boost**

Faster startup, trade loading and bulk edits, with less memory build-up on reloads.

### **Trade Ratings**

![Rating](https://github.com/user-attachments/assets/dfb780a3-c3fe-4aba-bd58-58cb43092d59)
Rate trades from 0.5 to 5 stars. Filter and compare results by rating, or convert a custom rating field.
_Access via Trade Note → Rating, or Trade Form → Details_

### **Journal Directly in Your DRC**

Edit journal fields and media in Trade Review cards, with customisable field placement.
_Access via DRC → Trade Review; configure in Layout Builder_

### **Day Trade Fields**

Apply journal fields to the day's regular trades, including later additions. Values set by hand stay yours.
_Access via Layout Builder → DRC → Day Trade Fields_

### **Trade Log Exports**

![Export](https://github.com/user-attachments/assets/bd66af46-7780-4f69-9613-4683743baf62)
CSV, JSON or Markdown exports follow filters, visible columns, order and sorting.
_Access via Trade Log → Export trades_

### **New Sync + Import Sources**

- **Hyperliquid Trade Sync** — Watch-only syncing for USDC perpetuals (Pro)
- **Trade Import** — Merrill Edge account activity, PropReports Executions and TradingView Strategy Tester backtests

### **Trade Entry + Sharing**

- **Trade drawer** — Create and edit without leaving your view
- **Multiple stop losses** — Split stops by percentage or position size
- **Backtest dates** — Carry execution dates and remember the last backtest day this session
- **Share cards** — Choose sections, image layout and P&L with a live preview

### **Accounts + Analytics**

- **Monthly Returns** — Trading returns separated from deposits and withdrawals
- **Expectancy Gap** — Compare net R per trade with your benchmark
- **MAE vs Realized PnL** — Compare adverse excursion with outcomes
- **Missed trades** — Filter and view them without adding hypothetical P&L to calendar totals
