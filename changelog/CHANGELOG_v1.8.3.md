# **[1.8.3] - 2026/08/14**

New performance widgets, review indicators, precise trade times, and reliability fixes.

### **Reviewed Calendar Indicators**

![Calendar Reviewed](https://github.com/user-attachments/assets/6af7fe07-fe68-4015-abe9-1d8510af95e0)
Completed daily and weekly reviews now appear on the performance calendar, with subtle dots in compact mode.

### **New Performance Widgets**

![Ticker widget](https://github.com/user-attachments/assets/01baab7e-2742-424f-ac0f-7f3d273b6e8c)
Compare the instruments, setups, and tags you trade.

- **Ticker Performance** — Rank tickers by Total P&L, Total R, or Win Rate
- **Setup Performance** — Compare setups on the Trading Dashboard
- **Tag Performance** — Analyze tags on the Dashboard and across all reviews
- **Flexible rankings** — View best and worst, best 10, or worst 10
  _Access via Layout Builder → Add Widget → Performance_

### **Key Events on Home**

![Key events](https://github.com/user-attachments/assets/76d437f5-1d43-434b-822c-5ad2e3d54489)
A new Home widget shows events from your current Weekly Review, grouped by day.
_Click the widget to open the Weekly Review_

### **Searchable Widget Picker**

![Search Widgets](https://github.com/user-attachments/assets/19b978e7-86ed-42ba-86df-0f89c42a0605)
Search Layout Builder widgets by name, description, category, or type.

### **Second-Level Trade Times**

Optionally record entry and exit times with seconds.
_Access via Settings → General → Show Seconds in Trade Times_

### **Filter Improvements**

- **Reset filters** — Restore defaults on Home and Setup Overview
- **Deleted account cleanup** — Removed accounts disappear from filters
- **Custom date range fix** — Custom timeframes now open and apply correctly

### **Trade + Workspace Reliability**

- Full exits now clear unrealized snapshots and close trades correctly
- Trade files outside the Journalit folder no longer appear as duplicates
- Restored DRC, Setups, and Trade Log tabs no longer load empty
- Backend sessions refresh automatically, reducing repeated sign-ins

### **More Fixes**

- Weekly break-even results now use neutral styling distinct from no-trade days
- Setup tag badges stay aligned across cards
