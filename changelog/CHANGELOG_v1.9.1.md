# **[1.9.1] - 2026/09/29**

Smarter filters, share images, a widget drawer, easier imports, and Arabic.

### **Smarter Filter Menu**

![Filter](https://github.com/user-attachments/assets/1534be6d-f063-4e30-a520-67a6c3d59ddb)
One filter menu across Dashboard, Trade Log, reviews, Home and Setups.

- **Exclusions** — Drop any value with the ⊘ button
- **Match modes** — Any of, All of, Only these or Exactly these
- **Prop phases** — Filter by individual account phases

### **Share Trades + Reviews**

Copy a trade note as a screenshot in one click, or share review cards with the widgets and sections you pick. Use the _Share current note as image_ command. With R multiples on, "Hide dollar amounts" keeps size private.

### **Widget Preview Drawer**

![Widgets](https://github.com/user-attachments/assets/45e4b8b8-870c-4c19-b67b-d44491578d6e)
Add widgets on Home and Dashboard from a side drawer with previews, tabs, and search.

### **Trade Import Upgrades**

- **Source first** — Pick your broker from a searchable grid
- **Import history + undo** — Delete past imports from the server in Settings → Trade Import
- **Header row** — Use your spreadsheet's own row number
- **Wrong-source prompt** — Get offered a switch when a file looks like another broker
- **Hyperliquid** — Previews use your device timezone

### **Layouts + Reviews**

- Better default layouts, including Daily Reviews by Weekday
- Empty Outside sessions log is back, with an option to hide it
- Home Drawdown and Profit Target widgets follow prop phase rules and let you choose accounts

### **Arabic + Lime Accent**

Full Arabic with RTL layout. Journalit defaults to a lime accent, or follows your Obsidian accent.

### **More Fixes**

- R mode never shows dollars where an R value exists
- Pro prompt for signed-out users in the Economic Calendar
- Correct payout balances on funded prop phases
- No more flashing or lost Trade Review status
