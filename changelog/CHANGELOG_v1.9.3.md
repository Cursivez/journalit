# **[1.9.3] - 2026/10/05**

Custom date ranges on Home, a Calmar Ratio metric, faster layout building, and more accurate prop account tracking.

### **Week and Custom Ranges on Home**

![Custom Range](https://github.com/user-attachments/assets/75f994f8-5f9a-4b2c-accc-94df71de15b3)
Filter your Home Overview by Week or any From/To date range.
_Access via Home → Filter → Period_

### **Calmar Ratio Metric**

See your annualized return relative to max drawdown.
_Access via Dashboard → Edit Layout → Add Widget → Calmar Ratio_

### **Insert Widgets Anywhere in Layouts**

![Layout Widget Add](https://github.com/user-attachments/assets/6aa9bfb2-a375-4d0a-a216-9160228d1cfa)
Hover between two widgets in the Layout Builder and click **+** to add one exactly there.

### **Prop Account Accuracy**

- **Live Balance** — Prop account cards, balance charts and drawdown rules follow your broker balance
- **Monthly costs counted** — Challenge stats and Eval ROI include subscription fees
- **Payout cycles** — Trading days and profitable days reset together after each payout

### **Dashboard + Review Polish**

- **Reorder metrics freely** — Drag Dashboard metrics between rows
- **Full review context** — Previous Trading Day Context and Daily Reviews by Weekday show all widgets, images and charts again
- **Update notices** — Release highlights appear in any view, with an option to turn off update reminders

### **Import Improvements**

- Clearer guidance for unsupported Rithmic files and mismatched Bybit headers
- Sync notifications separate new trades from updates such as late commissions

### **More Fixes**

- Long notes no longer cut off in Reading view
- Date fields keep the full year when typing 4 digits
- Trade forms fit narrow windows
- Trade Log custom field headers stay readable
- Links inside embedded playbook notes are clickable
- Fullscreen image arrows are visible in every theme
